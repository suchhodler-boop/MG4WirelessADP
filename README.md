# MG4 Wireless ADB

A small Android 9 utility for compatible MG4 head units. Tap **Enable Wireless ADB**, approve the Android RSA prompt if shown, and the app displays current IP addresses and copyable `adb connect` commands on TCP port **5556**.

Dark landscape interface, custom rounded popups, IPv4/IPv6 commands and copyable diagnostic details. No USB computer connection is needed for the enable workflow on supported firmware. The original APK has been reported working by the project owner; compatibility with other head-unit firmware is not guaranteed.

## Download and use

[Download MG4-Wireless-ADB.apk](apk/MG4-Wireless-ADB.apk?raw=true)

1. Park the car and install the APK using the head unit's file manager.
2. Connect the head unit and computer to the same trusted network.
3. Open **MG4 Wireless ADB** and tap **Enable Wireless ADB**.
4. Approve the Android RSA authorisation prompt if it appears.
5. Run the displayed command on a computer with Android SDK Platform-Tools installed. Authorise that computer on the head unit if requested.

The app verifies a local TCP listener, not connectivity from your computer. Vehicle firewall rules, network isolation and firmware differences may still block access. If no usable IP address appears, connect Wi-Fi and retry.

**Safety:** Use only while parked. Enabling ADB changes USB gadget configuration and restarts the ADB daemon, which may interrupt Android Auto. ADB is powerful: authorise only trusted computers, avoid public networks, and disable ADB through the head unit's available controls when finished. This app does not provide a disable button. No root, system-partition writes or firewall changes are performed. There is no automatic boot service.

## Compatibility and signing

- Targets Android API 28 (Android 9); minimum API 23.
- Package: `com.mg4.wirelessadb`, version 1.0.
- Requires the matching MG4 platform certificate and Android shared system UID 1000. This is **not** a generic wireless-debugging app for ordinary Android phones.
- The distributed APK uses the public AOSP platform test certificate also used by compatible MG4 firmware. Its certificate SHA-256 is `c8a2e9bccf597c2fb6dc66bee293fc13f2fc47ec77bc6b2b0d52c11f51192ab8`.
- Signing keys are intentionally not included. The original build used the public test keystore published with [lkernan/ADBUtil](https://github.com/lkernan/ADBUtil). A normal debug key cannot replace the matching platform key for system-UID installation.

## Build from source (Windows PowerShell)

Install JDK 11 and Android SDK **platforms;android-28** and **build-tools;31.0.0**. Ensure `java`, `javac` and `jar` are on PATH and point to the same JDK. Obtain the matching platform signing keystore separately.

```powershell
$env:ANDROID_SDK_ROOT = 'E:\Android\Sdk'
$env:MG4_KEYSTORE = 'E:\Signing\platform.keystore'
$env:MG4_KEY_ALIAS = 'platform'
$env:MG4_STORE_PASSWORD = 'your-keystore-password'
$env:MG4_KEY_PASSWORD = 'your-key-password'
.\build.ps1
```

Output: `dist/MG4-Wireless-ADB.apk`. Build intermediates and temporary data remain inside this checkout. No Gradle, external Java libraries or downloaded source dependencies are needed. The script verifies APK signatures after building. Build output can differ byte-for-byte because of tool versions and archive timestamps.

## How it works

The system-UID workflow enables `Settings.Global.ADB_ENABLED`, applies the MG4/AllGo USB gadget properties, and restarts `adbd`. If the daemon starts on port 5555, a small app-local ADB client performs normal RSA authorisation and requests `tcpip:5556`. It then checks that port 5556 is reachable locally and enumerates network addresses. RSA keys generated by that client remain in app-private storage; they are not published.

Source files are in `src/com/mg4/hardwareprobe/`; the Java namespace is retained from the original standalone prototype. This repository includes all app source and its build script, but no unrelated hardware probes, vehicle reports, SDK binaries or private keys.
